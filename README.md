# Bank-Account-Management-System

## Project Description
A console-based banking application developed using
Core Java and Object-Oriented Programming concepts.

## Features
- Create Savings Account
- Create Current Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- Transfer Money
- Display Account Details
- Custom Exception Handling

## Technologies Used
- Java 11
- OOP Concepts
- Collections Framework
- Exception Handling
- Interfaces
- Abstract Classes

## OOP Concepts Implemented
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Constructors
- Interfaces

## Project Architecture
- Model
- Service
- Repository
- Interfaces
- Exception
- Main

## How to Run
1. Clone the GitHub repository.
2. Open Eclipse IDE.
3. Import the Java project.
4. Run Main.java.
5. Follow the menu options.
